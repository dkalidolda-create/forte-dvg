# Forte DVG · Web frontend

Отдельный интерфейс HTML/CSS/JavaScript с Python/FastAPI-сервером. Локальные
стили, SVG и системные шрифты; нет CDN, внешней аналитики или облачных AI-запросов.
Дизайн: композиция Didit Transaction Monitoring, белая основа и бордовые акценты #A31551, цветовой ориентир — forte.kz.
Композиция и интерактивные три шага сохранены; страницы «О сервисе» и «Ограничения» удалены.

## Запуск на Mac

Из корня проекта в отдельном терминале:

```bash
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m frontend.app
```

Открыть http://127.0.0.1:8502. Старый Streamlit может оставаться на 8501;
при запуске старой команды он показывает ссылку на новый интерфейс.
На Windows используйте `.\.venv\Scripts\python.exe -m frontend.app`.

Backend продолжает работать на 8000, worker — в отдельном терминале.
Настройки API_KEY и MAX_UPLOAD_MB читаются из корневого `.env` только сервером.
BACKEND_URL по умолчанию http://127.0.0.1:8000; FRONTEND_PORT — 8502.
API-ключ не входит в HTML, JavaScript, публичную конфигурацию или URL.

## Реализованный сценарий

Главная → выбор MOV/MP4 и проверка размера → передача файла → опрос задания
каждые 2,5 секунды → результат или отдельная ошибка. Лимит ожидания UI — 5 минут.
Процент показывается только для реальной передачи файла, не для анализа.
Незавершённое задание можно восстановить после обновления вкладки (sessionStorage
хранит только ID, время начала и имя; сам видеофайл не сохраняется в браузерную БД).
После обновления исходное видео может потребоваться выбрать заново для просмотра.

При violation показываются несколько карточек, секунды от начала записи,
перемотка, переключение выбранного события, от 1 до 3 JPEG/base64 кадров,
увеличение изображения и источник. Неполная нормативная привязка явно отмечена.
При no_violation видео остаётся по центру. Ошибки и неполный ответ не дают
вердикт no_violation. Текст backend вставляется через textContent; нормативные
ссылки допускают только HTTP(S), кадры — локальный JPEG/base64.

Видеоплеер использует браузерные кодеки. MOV/MP4 с неподдерживаемым кодеком
принимается на анализ, но вместо предпросмотра выводится объяснение. Автоматическое
перекодирование исходного видео не реализовано. При поддерживаемом кодеке
перемотка выполняется по исходным секундам, без автоматического воспроизведения.

## Готовность ML

UI связан с настоящим API. В worker подключён локальный
ml.temporal_inference:analyze с 18 категориями разметки. Все 42 обучающих файла
обработаны с совпадением вердиктов и категорий; качество на новых данных не
подтверждено. Показатели: ML_RUNTIME.md. Повреждённое видео, отсутствие ресурсов
и таймаут остаются отдельными ошибками. Ответы по имени файла не подставляются.

## Проверка

```bash
python -m unittest tests.test_frontend -v
```

Проверяются серверное хранение ключа, передача файла, ограничения до разбора
multipart, защита от cross-site запросов, ошибки связи и согласованность ответа.
Браузерные прогоны используют только искусственное видео, отдельно от реального API.
Новые экраны адаптированы для одной колонки на телефоне и reduced-motion.

## Публичный gateway

`backend.public:app` объединяет UI и API на 9000. Публичный UI обращается
к API этого же процесса; отдельный development API на 8000 для него не нужен.
При изменении порта uvicorn задайте `PUBLIC_PORT` либо `PUBLIC_INTERNAL_API_URL`.
Обычный самостоятельный UI на 8502 использует `BACKEND_URL` (по умолчанию 8000).
