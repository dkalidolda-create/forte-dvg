## Зачем уточнять визуальную разметку

После исправления X-15 у нас только одно подтверждённое положительное
train-видео этой категории — X-26. X-4 и X-44 находятся в validation.
Метка всего видео не указывает модели, какие мелкие предметы — банкноты,
а какие — документы, и какой переход подтверждает завершение операции.
Новые кадры того же видео не считаются независимыми тестовыми примерами.

Подготовлена локальная страница: artifacts/grounding-review-v1/index.html.
В ней 75 кадров из четырёх train-видео; импортированы 56 кадров и 67 объектов.
Дальнейшие дополнения сохраняйте новой версией. Для первого прохода достаточно
вручную уточнить 8–12 кадров, сохраняя вариант «неясно», где доказательств нет.
Не меняйте исходный verdict ради совпадения с ответом модели.

Запуск из папки проекта:

```bash
.venv-ml/bin/python -m http.server 8767 --bind 127.0.0.1 --directory artifacts/grounding-review-v1
```

Открыть http://127.0.0.1:8767/. Выбрать X-26 около 8–12 с, выделить
видимые банкноты прямоугольником и отметить видимое состояние операции.
В X-15 банкноты не подтверждены: сумка отмечается отдельно как место хранения,
а импорт переводит её в collection_bag по явному уточнению команды.
Содержимое сумки не угадывать. На отрицательных X-5/X-27 отметить видимые
предметы и текущее состояние обслуживания. Если завершение не видно, выбрать
«Неясно», не угадывать. Для разметки важен контекст соседних кадров.

Кнопка скачивает cash_annotations.json. Координаты нормализованы, данные
сохраняются в localStorage, на внешние серверы ничего не отправляется.
Записи с состоянием «не просмотрено» и без прямоугольников/заметки не экспортируются.

Импорт проверяет версию данных, допускает только известные train-кадры,
отклоняет некорректные координаты и создаёт локальные вырезки объектов:

```bash
.venv-ml/bin/python -m ml.datasets.import_grounding --annotations ~/Downloads/cash_annotations.json --review-root artifacts/grounding-review-v1 --output data/processed/manual-grounding-v1
```

Это уточнение признаков и база для следующего эксперимента. Оно не означает
готовую обученную модель или 87% качества. Неотмеченный предмет не считается
размеченным отрицательным примером. Исходные verdict видео не меняются.

## Как сравнивать следующую версию

- Настройки и примеры выбирать на train; дубликаты между частями исключать.
- Считать accuracy, precision, recall, F1, coverage и balanced_accuracy_conservative.
- Последняя метрика усредняет долю найденных положительных и отрицательных
  видео; неопределённые/сбои считаются ошибками соответствующего класса.
- Не выдавать accuracy на train или точность отдельных соседних кадров
  за качество на новых видео.
- Для окончательного результата нужна отдельная группа съёмок/ракурсов,
  не использовавшаяся при выборе модели и настроек.

Worker пока не подключён к экспериментальным детекторам.
