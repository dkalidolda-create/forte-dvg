# Локальный ML-baseline на Apple Silicon

> **Архив экспериментов.** Этот документ описывает предыдущий этап разработки.
> Текущая модель и актуальная оценка: [ML_RUNTIME.md](ML_RUNTIME.md).

Экспериментальная модель: mlx-community/Qwen3-VL-2B-Instruct-4bit.
Лицензия весов: Apache-2.0. Исходная модель: Qwen/Qwen3-VL-2B-Instruct.
MLX-VLM распространяется под MIT и требует Python >=3.10.

Источники:
- https://huggingface.co/mlx-community/Qwen3-VL-2B-Instruct-4bit
- https://huggingface.co/Qwen/Qwen3-VL-2B-Instruct
- https://github.com/Blaizzy/mlx-vlm

Не менять существующий .venv API на Python 3.9. Для эксперимента нужен отдельный
Python 3.12 и .venv-ml. Это окружение только для Mac с Apple Silicon, не Windows.

## Команды после установки Python 3.12

```bash
python3.12 -m venv .venv-ml
.venv-ml/bin/python -m pip install -r requirements-ml.txt
.venv-ml/bin/python -m ml.datasets.download_model
```

Для актуального эксперимента с 4B дополнительно:

```bash
.venv-ml/bin/python -m ml.datasets.download_model --variant 4b
.venv-ml/bin/python -m ml.datasets.download_dino
```

Для повторения измеренного окружения Apple Silicon/Python 3.12 вместо
requirements-ml.txt используйте `requirements-ml.lock.txt`. Этот freeze-файл
фиксирует установленные версии; перенос на Windows или другую версию Python
не проверен. В нём могут присутствовать транзитивные аудиобиблиотеки, однако
наши обработчики не читают аудиодорожку и их не используют.

Установка библиотек и загрузка публичных весов требуют интернета. Инференс
выполняется локально без доступа к хабу. Загрузчики выбирают текущую revision
репозитория, затем записывают её в provenance; точное повторение исторического
прогона требует сохранённого снимка весов указанной revision.

Загрузка модели читает только публичный репозиторий весов. Скачиваются конфигурация,
токенизатор, шаблон и safetensors, без удалённого Python-кода. Версия фиксируется
в artifacts/models/qwen3-vl-2b-4bit/provenance.json. Для больших файлов проверяется
SHA256 из метаданных репозитория; прерванная загрузка может продолжаться.

## Пробный запуск

```bash
.venv-ml/bin/python -m ml.evaluation.benchmark_local --model artifacts/models/qwen3-vl-2b-4bit --output artifacts/benchmarks/synthetic-01
```

Первый тест создаёт искусственное изображение с цветным прямоугольником.
Он проверяет запуск модели и Metal, а не обнаружение нарушений.

После успешного запуска выполните тест на обучающем видео:

```bash
.venv-ml/bin/python -m ml.evaluation.benchmark_local --model artifacts/models/qwen3-vl-2b-4bit --video data/raw/videos/X-1.mov --output artifacts/benchmarks/video-01
```

metrics.json содержит время и пиковую память. response.txt хранит ответ модели
локально. Скрипт не печатает наблюдения по видео в чат/внешние сервисы.
HF_HUB_OFFLINE и TRANSFORMERS_OFFLINE включены до импорта библиотек;
вычисления используют локальный путь к весам, trust_remote_code=False.

Разреженная выборка из 4 кадров — только проба скорости. Она может пропустить
события и не доказывает отсутствие нарушения. До подключения к API нужно отдельно
реализовать временные окна, оценить положительные/отрицательные видео,
проверить новый ракурс и время обработки полного ролика.

ANALYZER_PATH в основном backend пока не менять: этот скрипт не реализует
контракт worker и не является готовым детектором.

## Первый замер на MacBook Air M4, 16 ГБ

- Искусственное изображение: загрузка 1,398 с, генерация 2,447 с,
  всего 3,845 с; пиковая память MLX 2,015 ГБ. Цвет определён верно.
- Х-15: выборка из 4 кадров, загрузка 0,781 с, генерация 3,361 с,
  всего 4,142 с; пиковая память MLX 2,546 ГБ.
- Версия весов: 9c4f5209e57b31f4b9dfba735de3fb983739c9cc.
- Ответ на видео является валидным JSON, но поле limitations из запроса
  отсутствует. До интеграции нужен строгий валидатор структуры и обработка
  неполного ответа; текущий текст нельзя напрямую считать ответом API.

Время не включает загрузку библиотек Python, чтение видео до модели,
сеть и очереди. Память — счётчик MLX, не общий расход памяти системы.
Четыре кадра не охватывают всю операцию; эти цифры не являются скоростью
анализа полного ролика и ничего не доказывают о качестве обнаружения.
Оба теста выполнены с отключённым доступом к хабу во время инференса.
