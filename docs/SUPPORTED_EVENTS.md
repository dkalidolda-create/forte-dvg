# Типы наблюдений и границы вывода

Реестр содержит **18 типов**, подготовленных по разметке команды. Наличие типа
в реестре не означает подтверждённую надёжность распознавания на новых видео.
Текущая модель обучена на 40 уникальных роликах; 42 файла включают две пары дублей.
Повторное совпадение с обучением не является независимой accuracy.

`conditional` — найдено применимое требование, но его условия нужно подтвердить.
`context_only` — найден только близкий нормативный контекст; прямой запрет
наблюдаемого действия в двух изученных документах не установлен.

| Код | Тип наблюдения | Связь | Источник и условия проверки |
|---|---|---|---|
| `cash_left_after_service` | Банкноты оставлены после обслуживания | conditional | №231, п.20, абз.2. Видимые ранее принятые деньги остаются вне закрывающегося устройства после операции; пересчёт сам по себе допустим. |
| `identity_check_not_visible` | Приём денег без видимой проверки документа | conditional | №231, п.19(1), п.7. Нужна полная последовательность до приёма. Отсутствие бумажного документа не исключает цифровую проверку. |
| `safe_left_open` | Устройство хранения оставлено открытым | conditional | №231, пп.20,80. Проверить принятые деньги, открытое состояние и завершение доступа; открывание во время работы допустимо. |
| `safe_not_locked_on_departure` | Уход при неподтверждённом запирании сейфа | conditional | №231, пп.20,80. Нужны непрерывные действия с замком и подтверждение незапертого состояния. Закрытая дверца без видимого поворота ключа недостаточна. |
| `safe_lock_rotation_not_visible` | Поворот ключа не виден | conditional | №231, пп.20,80. Требуется различимый механизм и непрерывный крупный план; скрытый рукой поворот не доказывает незапертый замок. |
| `collection_bag_left_unattended` | Пакет оставлен без присмотра | conditional | №231, пп.3(7),20,24,122–124. Проверить принятие, уход, статус подразделения. Содержимое закрытого пакета визуально неизвестно. |
| `bag_dropoff_client_departure` | Клиент оставил пакет и ушёл | conditional | №231, пп.17,20,24,106–107. Проверить вид передачи и оформление; документы могли оформляться иначе. Молчание без звука не устанавливается. |
| `overlapping_customer_service` | Пересечение обслуживания клиентов | conditional | №231, пп.20,21. Нужны незавершённая первая операция и начало второй с деньгами. Два человека в кабинете недостаточны; п.21 касается документов одного клиента. |
| `client_departure_during_operation` | Клиент ушёл во время приёма или пересчёта | conditional | №231, п.20, абз.1; п.31(4). Проверить продолжающуюся операцию. П.22 регулирует уход кассира, а не клиента. |
| `room_door_left_open` | Дверь рабочего помещения открыта | conditional | №14, пп.8,16(1),19(1). Установить, что это граница кассового узла и нарушена изоляция; не любая открытая офисная дверь запрещена. |
| `room_not_locked_on_departure` | Уход без видимого запирания двери | conditional | №14, пп.3,8,16(1),19(1). Установить тип помещения и фактическую доступность. Требование иметь замок не равно обязанности запирать любой кабинет при каждом выходе. |
| `cash_mishandling` | Сминание банкнот | context_only | №231, пп.3(6–7),19(2). Общий контекст сохранности и платёжности. Сминание, повреждение и неплатёжность — разные выводы. |
| `bag_unpacked_into_safe` | Банкноты извлечены из пакета и убраны в сейф | context_only | №231, пп.20,24–25,77,105,124. Не установлена универсальная обязанность хранить деньги в исходном пакете; вскрытие может быть частью процедуры. |
| `cash_split_at_end` | Часть банкнот у клиента, часть у сотрудника | context_only | №231, пп.20,31(3–4). Неизвестны назначение частей и сумма по документу. Нельзя выводить присвоение или недостачу. |
| `customer_enters_during_setup` | Клиент вошёл во время подготовки рабочего места | context_only | №14, пп.8,16. Общий контекст изоляции кассы; прямой запрет такого входа не найден. |
| `client_personal_items_on_desk` | Личные вещи клиента на столе | context_only | №231, пп.12,16. П.12 относится к вещам работников банка; переносить запрет на клиента нельзя. |
| `laptop_left_on` | Ноутбук оставлен открытым или с активным экраном | context_only | №14, п.5 — общий пожарный контекст. Нет требования выключать ноутбук; открытая крышка не доказывает отсутствие блокировки или питание. |
| `lights_left_on` | Освещение осталось включённым | context_only | №14, пп.5,14 — общий контекст. Нет требования выключать освещение при выходе; возможен дежурный или автоматический режим. |

Источники: [Правила №231](https://adilet.zan.kz/rus/docs/V1900019680),
[Правила №14](https://adilet.zan.kz/rus/docs/V2000020075).
Развёрнутое сопоставление: [NORMATIVE_MAPPING.md](NORMATIVE_MAPPING.md).

Сервис показывает предварительные сигналы. Таймкоды обучены по слабой разметке,
а кадры извлекаются из исходного видео. Человек проверяет событие, соседние секунды,
условия нормы и сведения, которые нельзя установить визуально. Результат не
является юридическим или дисциплинарным заключением.
